# Block Working & Shadow Blocks — Reference
## Source: Railway maintenance circulars, Rolling Block Programme (RBP) docs, G&SR
## Retrieved: 2026-09-04 | Tier 1/2 source

---

## Maintenance block
A period during which a section of track is closed to traffic to allow
maintenance, repair, or construction work. Train movement is suspended
in the block section for the duration.

## Integrated block
Multiple departments (Engg, TRD, S&T) carry out their respective
maintenance works **simultaneously within a single traffic block** on
the **same section**.
- Maximizes utilization of a single traffic stoppage
- Reduces total number of disruptions to train services
- Requires pre-coordination between department supervisors

## Shadow block
Maintenance work carried out "in the shadow" of a main block —
either in the **same or adjacent block section** during the same
traffic closure period.
- Can be in the same section (overlapping with integrated block concept)
  or in an **adjacent section** that benefits from reduced traffic
- Example: While a major Engg project (girder replacement) occurs in
  one block section, S&T or TRD departments utilize the "shadow" of
  that block to conduct maintenance in a neighbouring section
- Key benefit: significant maintenance output without creating
  additional, separate traffic disruptions

### Distinction:
- **Integrated block** = same section, same time, multiple departments
- **Shadow block** = same OR adjacent section, leveraging an existing
  block's traffic stoppage

## Rolling Block Programme (RBP)
- **Duration:** 26-week (or up to 52-week) advance plan
- **Purpose:** Plan maintenance blocks well in advance on a rolling basis
- **Requirements:**
  - Materials and manpower pre-positioned before block execution
  - Cross-department coordination (Engg, S&T, TRD inspectors)
  - Review at DRM (Divisional Railway Manager) level
- **Source:** Railway Board circulars, pib.gov.in

---

## Private Number (PN) exchange
- **What:** A pseudo-random number from a pre-printed secured book
- **Who:** Exchanged between Station Master (SM) and Section Controller
- **Purpose:** Authenticates safety-critical communications during
  block working
- **Used for:**
  - Granting/receiving Line Clear
  - Block back / block forward
  - Wrong-line running authorization
  - Signal defect movement authorization
  - Imposing/lifting speed restrictions
  - Power block authorization
- **Custodian:** Station Master holds the PN book
- **Audit trail:** Recorded on forms T/369(3b), Line Clear tickets
- **Source:** General & Subsidiary Rules (G&SR) — Tier 1

## Block types (per BDMS)
1. **Traffic block** — line closed to all traffic for maintenance
2. **Power block** — OHE power supply switched off for TRD work
   (line may still carry non-electric traffic)
3. **Disconnection** — specific signalling gear made inoperative for
   S&T work (disconnection memo issued, manual safety protocols
   until reconnection memo)
